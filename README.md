# Weather App ☀️

A simple web app that shows the current weather for any city. Built with **HTML, CSS and JavaScript**, using the **OpenWeather** API for weather data and the **Pexels** API for city photos.

<img src="images/screenshot.png" alt="Weather App screenshot" width="380">

## Features

- Search for a city, with autocomplete suggestions
- Current temperature, humidity and wind speed
- Weather icon that changes with the conditions (sunny, cloudy, rain, snow...)
- Card color changes with the temperature: blue for cold, yellow for mild, red for hot
- 5-day forecast
- A photo of the searched city
- Save cities to a favorites list

## How to run

1. Get two free API keys from [OpenWeather](https://openweathermap.org/api) and [Pexels](https://www.pexels.com/api/)
2. Copy `js/config.example.js` as `js/config.js` and add your keys
3. Open `index.html` in your browser
